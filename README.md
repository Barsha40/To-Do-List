
# To-Do List CLI App

## Description
A Python command-line application that helps users
manage daily tasks and stores them in a JSON file.

## Features
- Add new tasks
- Display all tasks
- Mark tasks as completed
- Store tasks in JSON format
- Load previously saved tasks
- Handle missing JSON files
- Handle invalid commands and task IDs

## Technologies Used
- Python
- JSON Module
- OS Module
- SYS Module

## How to Run

Add a task:
python todo.py add "Complete Python project"

View tasks:
python todo.py list

Complete a task:
python todo.py done 1

## Data Storage
Tasks are stored in tasks.json.
